# DeskPet 1.5 features (developer notes)

Both apps implement the host side identically; the companion engine and the shared HTML (panel, talk) are written once.
Ownership while building: engine/personalities/talk/panel = shared; `Sources/**` = macOS; `electron/src/{main,extras,agents,trips,sync,settings}.js`, `renderer/**`, `card/**` = Windows/Linux.

## 1. "What did the agent just do?"

- When a session changes to finished (where "all done!" and the notification happen today), read the session's last assistant text from its log:
  - Claude Code transcript JSONL: the newest `{"type":"assistant"}` record whose `message.content` has `text` blocks.
  - Codex rollout log: the newest agent message (`event_msg` `agent_message`, or `response_item` with `role: assistant` text).
- Summarize: drop fenced code blocks, inline code backticks, `**`/`__`/`#`/`>` markers, and links `[text](url)` → `text`; collapse whitespace; take the first sentence (up to `.`, `!`, `?` followed by space or end); cut to 90 characters with `…`. Empty → no summary.
- Show it: the finish bubble `Claude: <summary> ✓` (instead of only "all done!"), the notification body, the hover card row, and `state.sessions[].summary` (latest summary for that session, kept until the next finish).

## 2. Custom check-ins (engine only)

Generalizes the water log. Engine state `checkins: [{ id, emoji, title, kind: 'count'|'done', sentence, unit, target, every, enabled, builtin }]`.
- Built-ins (disabled by default except none): `eyes` 👀 "20-20-20 eye break" (done, every 20), `posture` 🪑 "Posture check" (done, 45), `stand` 🧍 "Stand up" (done, 60), `stretch` 🙆 "Stretch" (count, "I stretched for __ minutes", unit minutes, target 3, every 90), `meds` 💊 "Medication" (done, every 0 = only when you log it... use a daily time instead: `at: "HH:MM"`).
- `every` = minutes of activity between reminders (like water), or `at` = a daily time. Reminder: emoji + line `checkin.remind` with `{title}`, then offer the check-in talk (like water).
- Talk: count → fill-in sentence (`__` is the blank) with ranges relative to target: 0 → `checkin.zero`, < target → `checkin.some`, ≥ target and < 3×target → `checkin.met`, ≥ 3×target → `checkin.lots`. Done → choices "Done ✅" (`checkin.done`) / "Not yet" (`checkin.notYet`). Skip → `checkin.skip`. Vars: `{title}`, `{value}`, `{unit}`, `{emoji}`.
- Logged per day (`days[d]['ci:<id>']` value total, `'ci:<id>:n'` count) and lifetime counters. Any check-in done: +2 XP, small bond.
- Talk menu: Tell… → "✅ Check in…" submenu (water first, then enabled check-ins).
- UI ops (panel → `companion` op): `checkinSet {id, patch}`, `checkinAdd {emoji, title, kind, sentence, unit, target, every, at}`, `checkinRemove {id}`. `summary().checkins` lists them with today's value/count.

## 3. Insights page (charts)

- Host state `history`: last 14 days, oldest first, combined across synced devices: `[{ day, activeMinutes, agentMinutes, tasks, focusSessions, pets, openMinutes }]`.
- Engine `summary().days`: last 14 days of `{ day, sips, waterBreaks, mood, checkins }` (the engine keeps 35 days of day flags), and `summary().journal`.
- Panel page "Insights" 📊: this week vs last week tiles with change, a daily bar chart (time together, agent time), focus sessions, sips, and a mood calendar.

## 4. Quiet hours

- Setting `quietHours = { enabled, days: [1,2,3,4,5], from: "09:00", to: "17:00", notifications: true }` (`days` 0 = Sunday; `from > to` crosses midnight). Set with `set {key: 'quietHours', value}`.
- Active → treat as quiet (no remarks, no sounds; the pet still shows agent states). `notifications: false` also silences notifications.
- `state.quietHours` = the setting plus `active: bool`. The menu shows "🌙 Quiet hours until 17:00" while active.

## 5. Daily mood journal (engine only)

- Setting `journal` (on by default). After 19:00, once a day, when you're active and the pet can speak, it offers "How was today?" (5 moods) and an optional note. Stored in `state.journal[day] = { mood, note }` (kept 400 days). The trip talk's answers count for that day.
- Next morning after a "rough" or "tiring" day: the greeting is followed by an offered check-up (`journal.checkup`: "better / same / worse").
- Moods: `amazing`, `good`, `okay`, `tiring`, `rough` (same as trips).

## 6. Playdates

- Every running DeskPet (home and visitors) writes `~/.deskpet/presence/<pid>.json` each second: `{ pid, pet, x, y, width, height, at }` (bottom-centre of the pet, in that app's own screen coordinates; both pets on one computer are always the same app). Remove it on quit; ignore files older than 4 s.
- When another pet is present: the first time, and then at most every 3 minutes while both are idle, walk toward it and stop about one pet-width apart, facing it; then both play for ~4 s (petted/done poses, hearts) and `companion.event('playdate', { other, first })`.

## 7. Seasonal events

| id | dates | rewards (earned by 60 min together during the event) |
|---|---|---|
| `halloween` | 10-24 → 11-01 | `witchHat` (hat), `pumpkin` (companion) |
| `winter` | 12-15 → 01-01 | `santaHat` (hat), `snowman` (companion) |
| `valentine` | 02-07 → 02-14 | `heartAura` (aura) |

- Progress per event and year: setting `event.<id>.<year>` = minutes together (active minutes) during the event. At 60: unlock its rewards forever (setting `eventRewards`), wear them, `companion.event('eventEarned', { id, title })`.
- First launch on an event day each year: `companion.event('eventStart', { id, title })`; while active and nothing is worn in a slot, the event outfit shows (a preview) even before it's earned.
- Rewards list: event rewards appear with `event: '<id>'`, `level: 0`, locked until earned (lock text "🎃 Halloween event").
- Birthday (companion memory `birthday` == today): wear the party hat for the day if no hat is worn.
- Drawing: witch hat (tall black cone with a purple band and a bent tip, wide brim), santa hat (red cone, white trim and pompom), pumpkin (orange round companion with a stem and a carved face that bobs), snowman (two white circles, coal eyes, carrot nose), heart aura (pink hearts orbiting, like the other auras).
- `state.events = { active: { id, title, emoji, until, minutes, goal: 60, earned } | null, next: { id, title, from } }`.

## 8. Calendar heads-up (opt-in)

- macOS: EventKit (all calendars in Calendar.app, incl. Exchange/Google). Windows: classic Outlook through PowerShell COM (`Items.IncludeRecurrences`), when available. Everywhere: an ICS URL (VEVENT with DTSTART/DTEND/SUMMARY/LOCATION/URL/DESCRIPTION, `Z`/floating/TZID times, RRULE FREQ=DAILY|WEEKLY with INTERVAL/BYDAY/UNTIL/COUNT, EXDATE).
- Setting `calendar = { source: 'off'|'system'|'ics', icsUrl, lead: 5 }`. Skip all-day, declined, and cancelled events.
- `lead` minutes before a meeting: startled pose, `companion.event('meetingSoon', { title, minutes })`, a notification. At the start: `companion.event('meetingNow', { title })`. If a meeting link (Chime, Zoom, Meet, Teams, Webex URL in location/URL/notes) exists, clicking the pet within 10 minutes of the start opens it.
- `state.calendar = { system: bool (supported here), source, icsUrl, lead, status: 'off'|'ok'|'denied'|'<error>', next: { title, start, link } | null }`. Action `calendarTest` → `{ ok, events, next, error }`. Meeting titles never leave the computer.

## 9. Needs meters (opt-in, engine only)

- Setting `needs` (off by default). `state.needs = { energy, fun, coins }` 0–100.
- Energy drops ~10/hour of continuous activity and comes back with breaks (returning after 5+ idle minutes: +25, check-ins: +10). Fun drops ~8/hour and comes back with playing (petting +2, throws in playtime +3, games +10, talks +5).
- Below 25: gentle hints (`needs.tired`, `needs.bored`) at most once an hour, and the sleepy pose for tiredness. Nothing bad ever happens.
- Coins: 1 per 10 XP earned (hosts send `companion.event('xp', { amount })` whenever XP is gained). Treats (op `buyTreat {id}`): `cookie` 🍪 5 coins (+30 energy), `strawberry` 🍓 8 (+20 energy, +20 fun), `toy` 🧸 10 (+40 fun).

## 10. Sprite pack gallery

- `packs/index.json` in the repo: `[{ id, name, author, description, preview, files: [paths], license }]`, files under `packs/<id>/`. Fetched from `https://raw.githubusercontent.com/jacobsekai/deskpet/main/packs/`.
- Seeded with original recolors of the built-in cat (`midnight` black cat, `snowball` white cat, `ginger` orange tabby), rendered from the cat artwork into frames.
- Actions `galleryList` → `{ ok, packs: [{ id, name, author, description, preview, installed }], error }`; `galleryInstall { id }` → `{ ok, error }` (installs to `sprites/<id>/`; only plain relative paths inside the pack).
